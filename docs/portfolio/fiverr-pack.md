# Fiverr / portfolio pack (Phase 6)

Honest packaging for the Groundly white-label demo. No “automates 70%” claims — use measured eval pass rate.

## Gig title (example)

*I will build a custom AI support chatbot with RAG, citations, and admin dashboard for your business*

## Packages

| Package | Price band | Includes |
|---|---|---|
| **Basic** | $150–250 | Single-client deploy: PDF/FAQ ingest, chat API, embeddable widget, citations, fallback. Thin or minimal admin. Source code delivered. |
| **Standard** | $300–500 | + full admin (docs, conversations, leads, settings), branding, origin-bound key, live embed, deploy help |
| **Premium** | $550–900+ | + URL crawler, analytics/content gaps, handoff webhook (email/Slack), 30 days prompt/content tuning |

Clarify in gig text: **customized instance / source code**, not seats on a shared SaaS you bill monthly.

## Gallery shot list (4+)

1. **Logo lockup** on teal / product chrome (Groundly mark + wordmark)  
2. **Widget** — grounded answer with citation chip on the Riverside demo page  
3. **Leads inbox** — captured lead with transcript after an unknown question  
4. **Documents** — seeded FAQs/PDF with ready status  
5. (Optional) Settings embed snippet / architecture diagram for technical buyers  

## Loom script (60–90s)

1. Open the demo landing → click **Try the assistant** / open the bubble.  
2. Ask a grounded question (“Do you accept Delta Dental?”) → show streaming answer + citation.  
3. Ask something not in docs (“Do you accept Bitcoin?”) → bot admits unknown → lead form → submit.  
4. Cut to admin → **Leads** → show the new lead + transcript.  
5. (Optional) flash **Documents** or embed snippet in Settings.  
6. Close: “Grounded answers, citations, handoff — full source for your client.”

**On-screen text suggestion:** show eval pass rate from `scripts/run_eval.py` (“XX% on Riverside golden set”) — never invent ROI.

## Case study one-liner

Riverside Dental needed always-on FAQ answers without hallucinations → Groundly RAG + citations + lead capture → **measured** golden-eval pass rate + demoable handoff.
